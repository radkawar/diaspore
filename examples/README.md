# Examples

Run `make build` first, then follow each example's commands from the repository
root.

| Example | What it shows |
| --- | --- |
| [Embedding](embedding/) | One Python policy embedded in Python, Go, TypeScript and Lua hosts |
| [Packages](packages/) | Pure-Python PyPI packages compiled into a portable bundle |
| [Workflow](workflow/) | An order suspended and resumed across Python, Go and TypeScript |
| [HTTP](http/) | An HTTP server with explicit network access |
| [Key/value](kv/) | A TCP line protocol with an in-memory store |
| [Benchmark](benchmark/) | CPython and all four runtimes on the same workloads |
